POD WAWONA Private Backup

A personal utility for saving encrypted recovery copies of a print-on-demand application's files in its owner's Google Drive.

The owner authorizes the utility with Google. It requests access only to specific Drive files used with this app. It does not request unrestricted access to the owner's Drive.

Recovery archives remain in a private Drive folder. Restoring them requires the separately held recovery key. This utility does not publish artwork, run sales jobs, or change application approvals.
